# JobHunter contributor instructions

Follow [docs/RELEASE_POLICY.md](docs/RELEASE_POLICY.md): publish verified source changes to `shd2w/Jobs_hunter` and maintain the Pages launcher/private Codespaces path. No private workspace data or credentials belong in Git. Pages is static hosting, not the Python backend. Keep forwarded ports private and do not start paid infrastructure without permission.

Run `python -m pytest -q` after installing `requirements-dev.txt`. Use synthetic/disposable inputs. Original CVs must remain unchanged; preparation is not application submission. Record deferred or unverified checks honestly.
